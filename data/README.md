# Data

The data is proprietary and is not part of this repository.

To run the project, place the hackathon data folder at `data/Hackathon_data/` (or set
`HACKATHON_DATA_DIR` in `.env.local`), unpack the prediction file with `setup/unpack_data.sh`, and load
it into Zetaris with `setup/load_source_files.sh` (see the README and `docs/INSTALL_AND_CHECK.md`).
